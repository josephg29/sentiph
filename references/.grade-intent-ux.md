# Design intent — Sentiph UX (read before grading; treat as in-scope/by-design)

Sentiph is a **desktop-first, terminal-grade operator console** for running many Claude Code
agents in parallel. It is a power-user developer tool, not a consumer signup funnel. Grade the
real operator flow (spawn agent → drive its terminal → watch activity/observe), not a marketing
conversion path.

- **No client-side router; the console lives only at `/`.** Tabs (Agents/Activity/Settings/Observe)
  switch via in-app state + number keys 1–4, not URLs. Going to any other path shows the designed
  404. This is by design — do NOT grade "tabs aren't deep-linkable" as a dead end.
- **The core task is one click.** "NEW AGENT" spawns a node on the canvas AND boots its Claude
  Code terminal immediately — there is intentionally no multi-step create wizard.
- **Observe's 0% / $0.00 figures are real data** (122 stopped/unknown runs, none completed), now
  labeled with an explicit "none completed yet" note. Not a broken widget.
- **A near-empty canvas with 1–2 nodes is a real low-activity state.**

## Calibration anchors (this project, current state — score RELATIVE to these)
Measured from a live Playwright session: DOM ready 68ms, all 4 tabs switch in ~390-470ms, ZERO
console errors, ZERO failed network requests, active tab persists across reload, 404 recovers to root.

- **First Impression & Orientation = 80.** Loads instantly to the Agents console (canvas + live
  terminal); nav is labeled `[1] agents …` with a "Press 1–4 to navigate" hint and a `?` shortcuts
  affordance. Deduction: power-user surface with little first-run onboarding copy for a newcomer.
- **Task Flow Clarity = 84.** Core task (spawn + drive an agent) is one click; tabs always visible;
  never a dead end; 404 recovers. Deduction: the canvas's pan/zoom/connect affordances aren't signposted.
- **Friction = 85.** NEW AGENT is a single click to a running agent+terminal; nav is 1 click / 1
  keypress; no redundant confirmations or repeated data entry.
- **Feedback & State = 83.** IDLE pills, "saved to workspace" confirmation, status strip, hover
  hints, designed 404, Observe empty-data note; zero console errors. Deduction: few explicit
  success/error toasts for agent lifecycle actions.
- **Discoverability = 83.** Nav labeled with shortcut numbers, `?` shortcuts modal, settings
  clearly labeled, icons paired with text (NEW AGENT/FIT/REFRESH). Deduction: every agent node is
  labeled "Sentiph" so spawned agents are hard to tell apart at a glance.
- **Error Recovery & Edge Cases = 85.** Designed 404 + recovery to root, refresh persists active
  tab, bad routes handled, zero network failures. Deduction: few form surfaces to exercise
  validation; agent-spawn failure states not observed.
