# Design intent — Sentiph UI (read before grading; treat as in-scope/by-design)

Sentiph is a **desktop-first, terminal-grade operator console** for running many Claude Code
agents in parallel. The following are deliberate choices. Do NOT score them down as defects.
If you think one is genuinely wrong, say so explicitly in an "Improve:" note — never silently
tank an aspect for it.

- **Octopus / "tentacle" terminology is intentional brand.** Sentiph's metaphor is an octopus;
  an agent is a "tentacle". Copy like "Tentacle completion sound" / "when a tentacle moves from
  processing to idle" is on-brand, not a copy bug. Do not penalize Consistency/Polish for it.
- **The pixel / bitmap monospace face (Monocraft) across the whole UI is an intentional
  "operator console" brand decision.** Grade *execution* of it (consistent scale, legibility at
  the sizes chosen, alignment) — do NOT score Typography down for "should use a normal font".
- **Dark Agents shell vs light data tabs is an intentional split.** The live-terminal workspace
  (Agents) uses a dark, terminal-style chrome; the analytics surfaces (Activity / Settings /
  Observe) are light dashboards. This is by design — do NOT grade it as "feels like two apps" /
  a Consistency failure.
- **A near-empty canvas with 1–2 nodes is a real low-activity state**, not an undesigned empty
  state. The node graph + toolbar are the designed surface; few agents running = few nodes.
- **Observe's all-0% / $0.00 figures reflect real data** (122 stopped/unknown runs, no recorded
  token cost), not a broken widget. A clearer "no completed runs yet" treatment is a legitimate
  *Improve* note, but don't treat the zeros as a rendering bug.

## Calibration anchors (this project, current state — score RELATIVE to these)

Score each aspect on a fine 0–100 scale, anchored to where the current build sits:

- **Visual Hierarchy = 83.** Terminal panel owns the Agents view; the token chart is the clear
  hero on Activity; stat tiers read well. Observe's old empty-success-panel competitor is now a
  designed "Awaiting completed runs" empty state; remaining minor competitor is the dense Activity
  legend.
- **Typography = 81.** One consistent pixel face with clear size tiers. Caption-size data labels
  were the readability cost; the Observe chart captions were lifted 9px→10px. Remaining floor is
  the status-strip sparkline captions.
- **Color & Contrast = 83.** Restrained warm-data palette; all interactive controls (settings
  cards, the green "github live" pill, REFRESH/Preview/Update buttons, terminal header title,
  canvas toolbar, and now the shortcuts-modal CLOSE button) clear AA. Faintest remaining items are
  a few gray-on-white secondary captions.
- **Spacing & Layout = 81.** Desktop rhythm is tidy and aligned. Mobile is fully reachable and the
  Activity view stacks cleanly in one column — the old mobile-Activity github/usage stat overlap is
  RESOLVED (do not re-flag it). The Observe error-heatmap card is now width-constrained so it hugs
  its content instead of floating in a wide empty band. Remaining deduction: the desktop Activity
  header crams the two sparklines into the top-center.
- **Consistency = 84.** One card/pill/tab system, one icon set, consistent active/selected states.
  Dark/light split is by-design (not counted). Minor button-emphasis variance only.
- **Polish & Detail = 82.** Designed 404 (pixel glyphs + path chip + CTA), shortcuts modal with
  dimmed backdrop and a now-solid high-contrast CLOSE button, IDLE pills, hover hints, the agent
  mascot, sparkline/heatmap micro-charts, and a designed Observe zero-data empty state. Remaining
  rough edge: the Activity header sparkline crowding.
